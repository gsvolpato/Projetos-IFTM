# Projetos-IFTM

## Projetos

- [HC-SR04](https://github.com/gsvolpato/Projetos-IFTM/tree/HC-SR04)  
  Projeto que compara três módulos de sensor ultrassônico HC-SR04 para avaliar a consistência dos valores medidos. Os resultados foram publicados no [XI Seminário de Iniciação Científica e Inovação Tecnológica do IFTM (XI SIN)](https://iftm.edu.br/sin/2021/) em 2021 e também na [XIX Conferência de Estudos em Engenharia Elétrica (CEEL 2021) - ISSN 2596-2221](https://www.peteletricaufu.com.br/static/ceel/artigos/artigo_663.pdf).

- [RaspiarIO](https://github.com/gsvolpato/Projetos-IFTM/tree/RaspiarIO)  
  Projeto publicado no [XIV Seminário de Iniciação Científica e Inovação Tecnológica do IFTM (XIV SIN)](https://iftm.edu.br/sin/2024/), utiliza um Raspberry Pi como servidor local para banco de dados de apiário, integrando uma estação de monitoramento feita com ESP32 WROOM32 que mede peso, qualidade do ar (umidade, temperatura, fumaça, fogo) e presença.

- [DigiPot-EQ](https://github.com/gsvolpato/Projetos-IFTM/tree/DigiPot-EQ)  
  Projeto que será publicado no XV SIN de 2025 em breve.
